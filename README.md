A token launch radar that ranks pre-token DeFi protocols by implied launch value, computed from a sealed DefiLlama snapshot. It ships a sortable dashboard with a top-three spotlight, per-protocol model breakdowns with a one-line reason for each rank, and 8-step farm plans with costs and times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
